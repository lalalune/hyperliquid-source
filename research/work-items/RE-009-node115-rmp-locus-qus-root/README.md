# RE-009 #115 complete named Locus qus root comparison

Measure the ordered Address member stream and the separate count for named checkpoint field `exchange.locus.qus` at raw path `[0,9]`. The checkpoint and raw ABCI reference use independent SHA-256 pins. The verifier reproduces the reference's full raw digest and checks that the inner Context height leaf `[0,0,2]` independently matches H.

The selected named writer takes Locus `+0xb78` at `0x5480c5a`, emits key `qus` and hands off from `0x5677400` to `0x52ca1d0`. This writer opens the array using the set count and formats each member returned by `0x5138730` as a 42-character lowercase `0x` Address. Its normal tree lane and raw visitor `0x4511e20` both read the tree node's entry count at `+0xe6` and advance the ordinal. The raw visitor binds each Address as a 20-byte source at `8 + 20*ordinal`, and saves the original collection count from `+0x10` for a separate qword writer.

The raw constructor `0x450ed50` initializes two absent children. All members append to child 0, producing one BLAKE3 digest over their concatenation in checkpoint order. Child 1 is the digest of the little-endian count. The empty path produces only child 1. The comparator preserves record order while rejecting duplicate addresses. The earlier [#7657](https://github.com/lalalune/hyperliquid-source/pull/7657) covers independent top-level Exchange Address sets that use a different raw visitor.

Use the pinned helper source from [#7445](https://github.com/lalalune/hyperliquid-source/pull/7445), [#7404](https://github.com/lalalune/hyperliquid-source/pull/7404) and [#7344](https://github.com/lalalune/hyperliquid-source/pull/7344).
