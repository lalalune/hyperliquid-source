## Semantics, stated literally

The predicate takes (obj, index, flag) in (rdi, esi, dl) and returns
0 or 1 in al.

* Link byte: the qword at obj + 0x10 is loaded, then the byte at that
  pointer + 0x654. A zero byte returns 0 at once (0x5f6afb1 jumps to
  the `ret`); no count is read.
* Gate: otherwise the index is tested signed (0x5f6afb3) and its
  greater-than-zero bit is ORed with the flag low byte (0x5f6afb8).
  If both are zero, the predicate returns 0 at once; no count is
  read. Only the low byte of rdx participates; upper bits of rdx
  are ignored.
* Last-index test: otherwise the signed 32-bit count at obj + 0x54
  is read, one is subtracted with 32-bit wrap (0x5f6afbf), and the
  result is compared against the index as 32-bit patterns
  (0x5f6afc2). The predicate returns 1 exactly when they are
  equal, 0 otherwise.

Consequence, stated exactly: the predicate returns 1 exactly when
the link byte is nonzero, and (index > 0 signed, or the flag byte
is nonzero), and (count - 1) equals index as 32-bit patterns.
Because the subtraction wraps, count 0 with index -1 and a nonzero
flag byte returns 1 (0 - 1 wraps to the same 32-bit pattern as -1);
count 0 with index -1 and a zero flag byte returns 0 by the gate.

## Call sites and result dispositions (site only)

* 0x5f6b0e9 (inside 0x5f6b000): obj = r13, index = r15d, flag = 0
  (dl zeroed at 0x5f6b0de). The result is stored to the stack slot
  rsp + 0x10 (0x5f6b0f3) and later copied to the constructed
  record's +0x92 byte (0x5f6b257). The record's other fields and
  the caller's other behavior are NOT claimed.
* 0x5f73880 (inside 0x5f733c0..0x5f743d9): obj = rbx, index =
  r13d (the stack dword at -0x3a4(%rbp)), flag = the stack byte at
  -0x38f(%rbp), zero-extended. The result is zero-extended and
  pushed as a stack argument to the 0x5f40070 call at 0x5f738e8.
  That callee's semantics are NOT claimed.
* 0x5f92bce (inside 0x5f916f0..0x5f9360c): obj = r15, index = the
  stack dword at -0x2364(%rbp), flag = the stack byte at
  -0x208f(%rbp), zero-extended. The result is zero-extended into
  r8d, the fifth argument register of the 0x5f8bf00 call at
  0x5f92c3b. That callee's semantics are NOT claimed.
* 0x5f9a0e4 (inside 0x5f999d0..0x5f9a478): obj = r13, index =
  r14d, flag = 0 (dl zeroed at 0x5f9a0d9). The result is stored to
  the stack byte at -0xc71(%rbp); its later use inside the caller
  is NOT claimed.
