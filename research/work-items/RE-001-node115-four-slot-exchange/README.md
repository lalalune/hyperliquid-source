# RE-001: exchange of two 32-byte slots

- Component: unassigned code; #115 function map. This is a bounded static bind.
- Target: Linux x86-64 node #115, SHA-256 `a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301`.
- Source base: `8fd8db680ec4bfef40996e5616bce3d5156d0b86`; no external source or reconstructed Rust is used.
- Question: what does the complete body at `0x4333080` do to its input memory and what status byte does it return?

**Answer.** Read an unsigned 64-bit count `n` at `[rdi+0x30]`. If `n < 4`, the function writes no input memory and sets AL to `0x2c`. Otherwise, read a base pointer at `[rdi+0x28]`, exchange the 32-byte slot at index `n-4` with the 32-byte slot at index `n-1`, and return AL zero. The count and base fields are not explicitly written. On the short path only AL is assigned, but the upper bits of RAX are zero because the unsigned count is less than four; the full RAX return is therefore `0x2c`. On the exchange path `xor eax,eax` clears all of RAX. This assumes valid readable object fields, valid writable non-overlapping slot storage separate from the object, and address arithmetic without wrapping; fault behavior is outside the rule. Slot contents are opaque bytes.
