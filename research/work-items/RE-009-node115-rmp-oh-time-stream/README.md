# RE-009 #115 checkpoint oh ordered Time stream comparison

Compare the complete logical Time stream and row count of a nonempty named `exchange.oh` checkpoint sequence to a raw ABCI export at the same height. Row payloads remain outside the projection and are skipped during named decoding. The raw reference’s complete ordered reduction is still checked against its declared digest before comparing the two scoped leaves.

Exchange writer `0x5481584` routes field `+0x3d78` through named key `oh` in `0x5673ad0`. Sequence writer `0x52cf770` takes row count at `+0x18`, logical start at `+0x10` and traverses the logical deque sequence as up to two regions of 40-byte rows. Both regions call `0x53067a0`. The array-of-two writer calls the Time formatter for the row base and the nested payload formatter for `+0x10`.

Exchange slot 52 reaches `0x57b9ea0`. Its 40-byte native row enumeration binds descriptor `0x64b0310` and calls its writer against the same first child on each iteration. The row visitor `0x4e1a9b0` feeds the packed Time writer at `0x141b1e0` into that child’s first stream and the nested `+0x10` snapshot into a separate second stream. The first digest is BLAKE3 over a single concatenation of canonical little-endian 12-byte Time preimages in row order at `[52,0,0]`. Slot `[52,1]` receives the row count as an unsigned little-endian word. This comparison reports the nested branch shape and the two measurements independently. It leaves `[52,0,1]` opaque.
