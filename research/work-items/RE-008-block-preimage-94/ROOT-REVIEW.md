# Independent coordinator review

The existing consensus component exposes block authentication behind a caller-supplied interface. This contribution supplies the missing conditional selector-0 preimage and digest value APIs, with explicit packed time; it does not complete signature verification or the authenticator. Start with [README.md](README.md), [PROOF.md](PROOF.md) and [IMPLEMENTATION.md](IMPLEMENTATION.md).

The coordinator read the complete proof, ten newly selected full native bodies, the re-bound shared dependencies, complete source, tests, input-only client and build harness. An independent raw ELF/FDE/relocation parser checked the retained native extents and call bindings. Before source existed, a separate frame parser and closed integer calendar relation independently reproduced all 1,141 preimages. The optimized-Python static verifier passed 83 evidence controls and two regenerated trees. These controls qualify evidence admission, not execution of captured instructions. A separate peer reviewed the source and proof and found no actionable defect.

Author and coordinator each ran 126 actual commands under the pinned Rust 1.94.1 offline/locked graph. Both profiles passed 36 library and seven new integration tests. Baseline and same-path clean rebuilds each matched all 1,141 frozen cases, including hash-rate boundaries. All 17 compiled wrong implementations were detected in both profiles. All 38 value streams match across the two runs. Every one of their 504 stdout/stderr references was rehashed from retained actual streams. [ROOT-COMPARISON.json](ROOT-COMPARISON.json) records the results.

Within each run, same-path rebuilds reproduced the rlib and client bytes. Across author and coordinator directories, both rlibs and clients differed in both profiles; the cause is not established. No masks, normalization, cross-directory binary reproducibility or native machine-code equality are claimed.

The shared checkout previously passed `make doctor verify catalogue-check reproduce` after selecting GNU binutils on PATH. Its initial doctor failure from the default Apple tool selection and the corrected successful outcome are retained in `root-validation/shared-repository-checks.json`. This is a same-base shared static baseline, not a new full-suite run on this PR head. The full suite includes captured-instruction evaluators outside this static-only workflow and was not run. No hosted CI or Linux target result is claimed.

Packed words are raw inputs, not a claim of calendar validity. Signature validity, recovery, malformed memory, unwinding, allocator/ABI fidelity and full authenticator integration remain open.
