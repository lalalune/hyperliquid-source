Independence
  * MessagePack is hand-written from the MessagePack specification (oracle.py
    mp_* functions). No msgpack/rmp library and no Rust source is used.
  * Keccak-256 is a separate bit-level implementation (round constants from the
    FIPS 202 rc(t) LFSR, rho offsets from the (t+1)(t+2)/2 walk); it shares no
    table with `node115-sponge-permutation`.
  * Keccak-256 public vectors checked by the generator before it writes rows
    (each aborts the run on mismatch):
      ""      -> c5d2460186f7233c927e7db2dcc703c0e500b653ca82273b7bfad8045d85a470
      "abc"   -> 4e03657aea45a94fc7d47ba826c8d667c0d1e6e33a64a036ec44f58fa12d6c45
      "The quick brown fox jumps over the lazy dog"
              -> 4d741b6f1eb29cb2a9b9911c82f56fa8d73b04959d3d9d222895df6c0b28aa15
    These are the widely published Keccak-256 (pre-FIPS padding, domain byte
    0x01) vectors; they were recalled by the author, not fetched (no network),
    and they agree with the implementation. Additionally the same sponge with
    domain byte 0x06 equals the standard library hashlib.sha3_256 for all
    message lengths 0..400, which validates the permutation and multi-block
    absorption independently of the recalled vectors.
  * Anchor (a=1, t=2, nonce=0x0102030405060708, vault=None, expiry=None):
    input bytes  83a474797065aa7477617043616e63656ca16101a17402010203040506070800

    not. The digest equals the scouting-note preliminary value, which came from a
    different Python model; this oracle re-derives it independently.
