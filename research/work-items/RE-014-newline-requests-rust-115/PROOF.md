all32 branches, and proves its scalar/prefix/two-word/tail search equivalent
to first LF under immutable/nonwrapping bounded memory. Reuse that proof
unchanged; fresh Capstone/actual frame and raw-byte replay is not a fresh
GNU command or independent peer review. New Rust uses a scalar bounded search
and the same request/owned-store protocol. The README states the strict cursor
progress/slice invariant and callback/error ordering. The recorder monomorphizes
the same public generic function. Raw event comparisons use the existing
MIT abstract model and frozen vectors, not the Rust implementation as oracle.
The compiled mutants separately attack scan/indent/flag/failure/cursor behavior.
Native counterexamples parameterize only the actual scalar short path and
change real literal/immediate bytes; they are mathematical request equations,
not captured machine execution. Original callback callees and unsafe aliasing
remain assumptions/exclusions. No stronger whole-object ABI or completion claim.
