## What the window does

The window (0x5158ef0..0x5159130, FDE 0x00634b88) is the
refresh-then-render accessor for the report that 0x5157d30 builds:

- Null guard: if [outer+0x128] is 0, return 0 with the target
  untouched; no refresh, lock or render attempted.
- Refresh, flag inverted: otherwise call the timed snapshot
  refresh 0x514f270 with the flag byte XOR 1, then re-read
  [outer+0x128] (the refresh may replace the inner object).
- Lock: pthread_mutex_lock on the inner object itself; a nonzero
  result throws system_error.
- Copy: the whole 0x138-byte published snapshot at inner+0x28 onto
  the stack at rsp+0x00 — vector copies everywhere except the
  string slot at snapshot+0x20, copied by _M_assign from inner+0x48;
  tail fields at snapshot+0x120/+0x128 from inner+0x148 (8 bytes)
  and inner+0x150 (16 bytes). The stack slots at snapshot+0x00/
  +0x10/+0x120/+0x128 are zeroed before the lock and then
  overwritten by the copy (recorded as observed dead writes).
- Unlock, then render: pthread_mutex_unlock on the inner object
  BEFORE calling the builder 0x5157d30 with (stack snapshot at
  rsp+0x00, render target, clock holder at [outer+0x780]); the
  builder mutates the target in place, so this window builds no
  temp string and performs no move-assign.
- Dispose and return: dispose the snapshot identity string (sized
  delete only when its pointer differs from its own SSO buffer at
  rsp+0x30, size = capacity + 1), return 1.
- Exception cleanup (0x5158ebe..0x5158eee, FDE 0x00634bd4) has two
  entries: full (unlock + dispose + resume) and dispose-only; it
  never disposes a temp string because this window builds none.
  Which landing stub serves which call site is not claimed (LSDA
  mapping).
- Reaching path: the window has no direct caller in .text; it is
  reached through two tail-jump thunks fixing the flag byte —
  0x5159130 passes flag 0 (refresh gets flag 1, aggressive
  thresholds) and 0x5159140 passes flag 1 (refresh gets flag 0).
  Neither thunk has a direct caller either, so their reaching path
  is unclaimed.

Callees cited only, not re-claimed: 0x514f270 timed refresh
(RE-001-timed-snapshot-94), 0x5157d30 report builder (no packet
yet). Distinct from the 0x514fd60 refresh-render accessor
(RE-001-refresh-render-94): same guard, flag inversion, lock and
snapshot shape, but a different render callee, a different stack
snapshot base, no temp string and no move-assign.
