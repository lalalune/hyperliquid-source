# RE-009: reconstruct the node #115 ensure-directory and atomic-write helpers (0x15020f0, 0x15024a0)

This packet lets an independent reconstruction reproduce exactly how node #115 creates a missing directory (mode 0x1ff, recursive) and how it publishes a file atomically (temporary name, content write, parent-directory creation, move onto the target): 13,599 byte-derived cases agree with an independently written Python model of both real function bodies, and 53 of 53 negative controls are detected.

- Component ID: `RE-009` (storage and state output; the helper is the sink of the state-export router bodies).
- Target release and full SHA-256: Linux x86-64 node #115, `a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301`.
- Source commit / reference commit: repository `0781ce04826eeefd89fe336cb8ea073be0c1de30`; reference sources were not consulted for this packet.
- Claim status: instruction bytes, FDE extents, relocated call slots, branch targets and constants are observations. The behaviours below (what the bodies do with the answers of each callee role) are reconstructions proven only against stubbed callees; the real identity of every callee role is unresolved.
- Scope included and excluded: the two bodies and the exact order and arguments of their callee calls. Excluded: the bodies of the callee roles (0x5cab560, 0x5c8e8c0, 0x16815e0, 0x1500a60, 0x5c8f4c0, 0x1501360, 0x141e3a0, 0x1502f90, 0x5ca5110, 0x1502da0, 0x1500b90, 0x15026e0, the deallocator), the callers, and any operating-system behaviour.

## Reproduce

From the repository root, with the Python 3 standard library only (no binutils; the node is never executed):

```
python3 tools/re009_atomic_write_115.py --out research/work-items/RE-009-atomic-write-115
python3 -m unittest tests.test_re009_atomic_write_115
```

The tool checks the SHA-256 above first and fails otherwise. It reuses the evaluator in `tools/decimal_scaled_u64.py`. Output is deterministic (no clock, no random, no paths); peak resident memory about 460 MB, about 25 s. `MANIFEST.sha256` lists every generated file.

## Evidence

Coordinates are virtual addresses of the loaded image. All numbers below are produced by the tool from ELF bytes.

| body | FDE | instructions | reached by the cases | cases |
|---|---|---|---|---|
| `ensure_dir(ptr, len)` | 0x15020f0..0x15021c2 | 61 | 61 | 3,953 |
| `write_atomic(content_ptr, content_len, path_ptr, path_len)` | 0x15024a0..0x15026d1 | 148 | 126 (the other 22 are unwind cleanup pads) | 9,646 |

`calls.tsv` lists each body's call sites in byte order with the relocated slot target and the role the tool gives it. Roles are named only by use:

- `A` (slot 0x64e0938 -> 0x5cab560): takes a request `{ptr, len, byte 6, word 0x201, flag}` where the flag is `len != 0 && first byte == '/'` (0 for an empty path); writes a tag byte.
- `B` (0x5c8e8c0) and `C` (0x16815e0): run only when the tag byte is 7, 8 or 9 (`add 0xf9; cmp 3; jae`); `B` returns a pointer, `C` is called only when it is non-null and writes a `{u32 discriminant, ptr, len}` record. The record replaces the path unless the discriminant is exactly 1.
- `D` (0x1500a60): exists check, boolean in `al`.
- `E` (0x5c8f4c0): create directory; the body prepares `{u32 0x1ff, byte 1}` (mode 0x1ff, recursive) and passes the path. A non-zero answer is wrapped by `F` (0x1500b90).
- Write body only: `S1` (0x1501360) and `S2` (0x141e3a0, with rodata pointer 0x44b7f0 and callback 0x14fcb40) build a formatted string; `S3` (0x1502f90) turns it into a temporary-path `String {cap, ptr, len}`; `S4` (0x5ca5110) writes the content to it; `W` (0x15026e0) wraps a write error with the target path; `S5` (0x1502da0) moves the temporary file onto the original path; the deallocator slot 0x64df4a0 -> 0x635de30 releases every string.

`cases.tsv` holds every 12th case plus any mismatch with the real outcome; the full set is regenerated by the tool. `mutants.tsv` lists each conditional jump and each compare or constant-store immediate of both bodies, flipped one at a time. `variants.tsv` lists the deliberately wrong reconstructions and the number of cases that catch each. `summary.json` and `measure.json` hold the totals and the per-body result digests.

## Implementation and comparison

`ensure_model` and `write_model` in the tool are the independent reconstruction. For each case the evaluator runs the real bytes with every callee replaced by a logging stub, then the return word and the ordered log of (role, argument values) must equal the model's. Reconstructed behaviour:

1. `ensure_dir`: build the request and call `A`; if the tag is in 7..9 call `B`, call `C` only when `B` returned non-null, and take the record's (ptr, len) unless its discriminant is 1; call `D`; if it exists return 0; otherwise call `E` with mode 0x1ff and recursive=1, return 0 when `E` answered 0, else return what `F` returns for the error.
2. `write_atomic`: `S1`, `S2`, free the first string if its capacity is non-zero, `S3` (temporary name), free the formatted string if its capacity is non-zero, `S4` with the content. On a non-zero `S4` answer call `W` with the error and the target path and return its word, with no directory work or move. Otherwise run the `ensure_dir` logic on the target path (A/B/C/D/E/F inlined; a mkdir failure returns `F`'s word and skips the move), then `S5` with the temporary name and the original path (not the replaced directory) and return its word; finally free the temporary string if its capacity is non-zero.

Negative controls (53, all detected): 10 wrong reconstructions of `ensure_dir`, 8 of `write_atomic`, 16 inverted conditional jumps and 16 changed compare or constant immediates in reached code, a wrong digest, a non-FDE-start address and an address outside every FDE. Three jumps lie only on unwind pads and are reported as unreached.

## Results and limitations

- Cases 13,599, mismatches 0, negative controls 53, detected 53 (`measure.json`).
- The callee roles are stubbed; whether `E` is a recursive directory builder, `S5` a rename and `A..C` path-component helpers is inference from argument shape and the 0x1ff/recursive constants only.
- The 22 unwind cleanup instructions of the write body are not exercised.
- No gate is requested.
