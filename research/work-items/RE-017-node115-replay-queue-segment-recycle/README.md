# RE-017 · Queue segment watermark and recycling

Target Linux x86-64 Node #115 SHA-256 a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301. The 16-byte queue producer at 0x581b0c0 and probe at 0x581a100 contain a segment-management path distinct from their per-slot payload stores and loads.

In the producer's selected linked-segment path, a low dword of all ones at segment +0x210 and the current local advancement flag permit a compare-and-swap of the producer's segment pointer from the previous segment to its successor. On success the code executes a locked zero OR on its stack, loads the current reservation word from producer descriptor +8 and stores it at the previous segment's +0x218. Only then does it set bit 32 at the previous segment's +0x210 with a locked OR. Bit 32 therefore has a separate publication path from the per-slot bits in the low dword.

After resolving the reader's selected segment, the probe compares it with the older segment pointer at reader descriptor +8. If the pointers differ, bit 32 of the older segment is set, and its +0x218 word is at most the current reader index, the selected recycling branch runs. It advances the older-segment pointer to its successor, clears the retired segment's base, link and flag words, and gives it a new base equal to the selected producer segment's base plus 32. It attempts to attach the reset segment to a null +0x208 link. On contention it can try twice more using the non-null predecessor links returned by the failed comparisons, recomputing the base each time. The selected third failure invokes the release slot with size 0x220. These paths assume valid descriptors and the observed queue layout. The analysis does not establish complete interleaving or memory-reclamation correctness.

Run `python3 research/work-items/RE-017-node115-replay-queue-segment-recycle/verify.py` from the repository root. It checks both extents and the selected byte windows. Seven synthetic inputs cover segment identity, the separate publication bit and unsigned watermark boundaries.
