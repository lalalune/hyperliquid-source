On the selected TLS fast path, a byte at FS-0x410 equal to 1 takes `0x2ae1ac0`; it dereferences the cell pointer held in R15, adds 16, and calls `0x5cfdb90`. The alternate getter at `0x2ae1ad6` returns to that same call on a non-null result. If the call returns normally, `0x2ae1acc` jumps to `0x2ae19e0`, whose selected continuation reaches the executor call again.

Combining with #6773, an inner nonzero result and persisted state 3 or 4 can conditionally reach the outer helper and re-enter the corresponding inner poll path. This assumes the selected TLS branches, same object and valid pointers, normal returns and no intervening mutations; exact wait duration, fairness, helper behavior and live scheduling are not established. No claim is made about checkpoint height or node completion, and no captured target executes.
