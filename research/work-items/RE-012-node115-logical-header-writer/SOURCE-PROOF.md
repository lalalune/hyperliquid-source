# Source argument before execution

This proof binds the independently authored library to design freeze62d74a75.
It is not an execution result. The native relation remains conditional on the
separately frozen map/cache/probe and finite actual-chain invariants.

`Name` derives tagged byte equality, so cross variants and different byte case
remain unequal. `spellings` scans actual groups and returns their value slice;
no supplied index/hash/answer is accepted. Prior duplicate rejection gives a
unique match. `chosen` selects occurrence index with `get`, preserving a present
empty spelling, and falls back only when no such occurrence exists. Builtin table
indexing is safe after the global ordinal pass; the81 literal bytes are directly
transcribed from the already raw-authenticated target table.

`append`'s global loops implement the error priority literally. The Copy array of
map references is visited primary then spelling in each pass. Duplicate search
only examines earlier indices and stops at the first repeated tagged name. Every
validation/planning function sees immutable input. `representation` is reached
only after all groups are nonempty, so values.len()-1 is defined; every sum/product
is checked and the two native strides per map are104/72 and96/64. Neither the
stride rule nor its host error pretends to validate raw native pointers.

The length pass begins at used and visits each actual primary value in order.
It checks addition of chosen-name length, then3 for an empty value, otherwise4
and value length. The final isize bound precedes capacity. No capacity error can
mask a later overflow. All fallible operations finish before the first output
write, so every Err preserves every byte, including unused suffix.

The write traversal repeats the same exact immutable lookup/choice. For each
occurrence, name output has exactly name.len() bytes. The title-case condition
requires capitalization, fallback, prior emitted '-' and ASCII lowercase; its
subtraction is in97..122 so cannot underflow. Previous starts '-' and is assigned
the emitted byte. A nonempty value adds1colon+1space+len+2CRLF; an empty adds1+2.
By induction, position equals the length pass's partial sum. All partial sums are
at most required, because addends are nonnegative, and required<=output.len().
Every write/slice endpoint is therefore in bounds and its arithmetic cannot
overflow. No fallible operation remains during this traversal. Its final position
equals required. Only [used,required) is changed; prefix and suffix stay identical.

The literal test transcriber does not implement this relation. It writes each
frozen input as Rust byte/group literals, and writes each already frozen expected
result as a literal assertion. The input-only probe uses the same input setup but
contains no expected fields. Separate parent TSV records project the frozen
expected used bytes plus the specified untouched suffix; no result is derived
from primary/spelling input. Count plans produce real borrowed-group arrays when
tests/probe run; oversized arithmetic examples remain proof obligations only.

Qualification will require exact source pins, both host profiles and full46-row
normal probe outputs. Mutants must compile, exit normally, produce complete
canonical output and differ at their predeclared frozen witness. Compiler failure,
process panic/timeout and malformed/truncated output are inconclusive, not kills.
Linux output will only be compiled, never executed. No native capture is passed
to any compiler, test or probe.
