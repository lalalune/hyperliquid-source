# RE-009: snapshot sibling secondary cleanup layouts

The value+0x20 cleanup reached by #7210 splits on the signed-minimum sentinel. The nonsentinel route calls 0x24fc7a0 on the descriptor and, for a nonzero first word, tail-calls the release slot with the original pointer and that word times 224. The sentinel route constructs a cursor descriptor and calls 0x244b6e0. Each nonempty result projects the returned key index into a 216-byte record. The dword at record +0x60 selects an extra eight-byte offset only when equal to two. At that offset the first selected pair uses size and pointer positions +0x90/+0x98, scaling size by eight. The second uses +0xb8/+0xc0, scaling size by 32. The second skips both zero and the signed-minimum marker. It then requests the next cursor item. These are observed normal paths with valid descriptors. The field types, surrounding exception tables and runtime reachability remain open.

The packet uses ELF virtual addresses and the pinned #115 digest listed in the offline log. Run python3 research/work-items/RE-009-node115-snapshot-sibling-secondary-drop/verify.py from the repository root. The verifier checks relative edges and independent instruction anchors and rejects a mutation to each.
