# Seeded Visor key value: implemented and host qualified

The real dependency-free [visor-key-hash crate](../../../src/visor-key-hash/README.md) now closes the hash-value dependency previously left opaque by the Visor lookup packet. `hash_key([u64; 2], &[u8]) -> u64` handles the exact seed order, every original byte, one implicit FF byte, little-endian words, the projected length byte and complete 64-bit result. The safe `no_std` library allocates nothing and forbids unsafe code. It is one whole-input API; no table or generic streaming API is introduced.

The target, native scope and conditional proof remain the immutable [pre-code README](README.md), [PROOF.md](PROOF.md) and [CONTRACT.md](CONTRACT.md). The complete value graph is 823 bytes / 231 native rows; another 887 bytes / 219 rows supplies caller/lookup context. No native-byte credit or component gate changes. The selected graph uses no imported helper or allocator, and the storage/frame/read-domain premises are explicit. [BRIDGE.md](rust-validation/BRIDGE.md) explains the independent safe-source decomposition and actual input-only comparison boundary.
