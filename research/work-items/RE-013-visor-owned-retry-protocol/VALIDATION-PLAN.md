# Pre-source and later source qualification

This phase qualifies a conditional protocol contract, static evidence bindings
and an independently stated finite event oracle. It does not compile Rust or
execute the captured target. Root and peer reviews are separate admissions;
the author cannot substitute their planned existence for an actual result.

`collect.py` admits the complete ELF SHA/size and tool executable hashes before
decoding a private mode0400 snapshot. GNU and LLVM exports must independently
tile the same ten exact FDE bodies. Full raw CIE/FDE, selected LSDA tables,
unwind-header entries, all15,595 RELA records searched for interference,18
selected slot bindings, data literals and numeric operands are checked.
Protected code/unwind ranges cannot have a relocation writer. Selected
relocated literals admit only their explicitly bound writers. This is file
evidence admission, not validation of the running loader or native semantics.

`bind.py` exposes the raw field checks separately from the whole-image and
body hashes. The verifier mutates actual image file offsets derived through
PT_LOAD and requires the intended literal/operand/instruction/frame/index/
relocation check to reject the change while both hash gates are bypassed.
Changing a claimed branch destination with unchanged instruction bytes also
must fail. These controls test actual binding logic; they do not prove a
semantic theorem about the corrupted executable. `PROOF.md` supplies the
address-bound ordinary-return argument. Exceptional paths remain explicit
limits even though their full bytes are retained.

The mathematical oracle uses exact Fraction conversion and a single
unbounded total number of nanoseconds. The future implementation will call
the existing integer converter and maintain a canonical pair with unsigned
chunk subtraction/add-back. Both share the same stated contract, not code or
generated expected data. The finite oracle covers775 histories:727 conditional
ordinary-domain histories and48 new safe refusals. Independent observers must
test supplied object identity, last-error liveness, returned terminal identity
and precise creation/destruction order, including unused response laziness.

Pre-source verification rehashes all336 unchanged prior1599 manifest entries,
checks arithmetic certificates, parses every input-only frame, reproduces its
expected events, and regenerates native exports/arithmetic/corpus into two
fresh directories. Full physical packet admission rejects extra/missing files,
symlinks and unexpected directories against the externally pinned final freeze.
Python normal and -O runs must agree, with no reliance on removed assertions.
Runtime caches are excluded rather than blessed as additional evidence.

Ten pre-source Python specification mutations are sensitivity controls only.
They are not claimed as future Rust mutant kills. Later, root-approved source
qualification must run the actual two-package graph in both debug/release,
with the original duration crate byte-identical, no registry dependencies,
offline locked resolution, full source/config/ancestor/toolchain admission,
and an input-only client. The comparison harness alone receives expectations.
Malformed transport returns exit2 with no stdout prefix; library safe refusals
are ordinary value outputs. Raw stdout/stderr and failures are retained.

The later Rust mutation plan targets these substantive distinctions:

| Group | Required distinct changes to challenge |
|---|---|
|Selection|omit initial attempt; None becomes empty; supplied empty becomes default; change a default word; change fixed owned schedule; change owned description|
|Timing values|suppress attempt after zero duration; signed/incorrect chunk cap; omit retained seconds; consume code0 remainder; change raw clock/flags; stop on code4 instead of resuming|
|Ownership|drop old E before next attempt; lose/drop replacement E; call terminal after dropping last E; pass only a suffix schedule; fail to preserve supplied terminal identity|
|Owned cleanup|cleanup before command release; skip present empty cleanup; omit cleanup-error destruction; let cleanup failure replace retry outcome; destroy P before cleanup error|
|New policy|accept invalid code4 remainder; treat unexpected raw code as completion; run optional cleanup on safe refusal|

Each actual mutation must be uniquely bound to frozen source coordinates,
compile successfully in both profiles and emit the complete775-case stream.
Mismatch counts must separate the727 conditional cases from48 policy cases.
A compile failure, timeout, abort or partial stream is a qualification failure,
not a semantic kill. If a type-safe source design makes a planned mutation
inexpressible, that must be stated rather than inventing a count.

Independent clean source copies, retained private compiled artifacts and
cross-author/root value streams will be compared. Debug executable differences
may be reported without masking or an unsupported cause. No shell, preflight,
OS sleep, GPG, filesystem cleanup, elapsed time or node progress claim is part
of this qualification.
