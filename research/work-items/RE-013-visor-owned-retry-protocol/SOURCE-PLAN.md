# Planned two-package source graph

Root selected one extension of existing PR1599, with no additional PR count. Its exact existing src/visor-duration-value component and all original historical evidence remain unchanged. The new real component is planned at src/visor-retry-protocol, with one explicit local path dependency ../visor-duration-value. Both packages will be delivered in the same atomic PR head. There is no separate pending-PR runtime dependency, copied converter, fake root workspace or graft into the unrelated allocator-class module.

Before source authorship, this phase will pin all existing duration crate files, original native proof/contract, pre-code/source/amendment/final qualification identities, and the unchanged converter implementation. The independent pre-source oracle will derive raw-bit durations using exact rational arithmetic and the prior proven conversion partition, not load expected values from a source implementation.

The future library will use owned generic request/error/terminal/cleanup values where required for identity/drop-order tests, borrowed ordinary attempt callbacks, a supplied sleep-response callback, and a borrowed terminal-builder callback. It will preserve lazy evaluation, the complete selected raw-bit delay list, normal failure ownership and optional-cleanup result preservation. Exact public signatures and safe refusal semantics will be frozen before any Rust/client code is written. Safe interfaces are new and do not reproduce an original ABI or allocator layout.

The independent event oracle will model sleep as a nonnegative integer number of nanoseconds and a callback transcript, while production may use the already qualified duration pair and iterative chunk control. Input IDs will be opaque. Case names, domain labels, expected values and semantic annotations stay outside the future input-only client. The client will link the real two-package graph and receive only encoded supplied inputs/responses; the comparison harness alone will receive expectations. The corpus will include ownership/drop identities and full event order, not only final status or counts.

Later graph admission must cover both actual Cargo manifests/locks, all source/test files, licenses, symlinks, lexical and canonical ancestor Cargo.toml/.cargo configuration, environment, hooks, exact metadata packages/targets/dependencies, offline locked resolution, pinned97-file toolchain payloads, and actual linker/SDK limitations. No dependency installation or network is part of qualification. Only targeted new tests and separately approved existing duration tests may run. A source/client/harness freeze and independent root/peer build gate will precede compilation.

Fresh separate author/root directories, exact raw stdout/stderr and command receipts, full finite corpus outputs, compiling semantic mutants, independent clean rebuild comparisons and retained private compiled artifacts will be required. Public archives will exclude compiled binaries and runtime caches, retain exact evidence streams and failure chronology, and distinguish native-conditional cases from new safe policy. Debug executable differences will be reported without masks or an unsupported explanation.

This file is a pre-code plan. No new Rust, client, build harness or source workspace has been authored.
