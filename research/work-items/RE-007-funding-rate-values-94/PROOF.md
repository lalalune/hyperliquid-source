## Floating relation and operation order

Assume Intel SSE binary64 semantics with nearest-even rounding, DAZ=FTZ=0, all floating exceptions masked, and stable controls throughout this call. No target processor or MXCSR was measured. Integer implementation of this explicit relation will be portable as values; native correspondence remains conditional. Floating status flags, faults and asynchronous events are not output fields.

Finite arithmetic is the exact real operation rounded once to binary64, including gradual underflow and overflow. Exact additive cancellation yields +0 under nearest-even, except adding two negative zeros yields -0. Product/division zero and infinity signs use XOR. Signaling NaNs become quiet by setting fraction bit51; an existing NaN retains its sign and remaining payload. If both arithmetic inputs are NaNs, the first source (old SSE destination) is selected. If just one is NaN it is selected, before non-NaN invalid rules. Invalid non-NaN operations, such as opposite infinities added, equal infinities subtracted or infinity times zero, produce `0xfff8000000000000`. SUBSD must select NaNs before any mathematical second-operand sign inversion. This preserves the original second-operand NaN sign.

The arithmetic source is [Intel SDM Volume1, 253665-080US, June2023](https://cdrdv2-public.intel.com/782149/253665-sdm-vol-1.pdf), §4.8.3.5/Table4-7 and AppendixD/TableD-1 (printed4-16,D-5/D-6), with §4.8.4 rounding controls. The finite MINSD/MAXSD source is [Intel SDM Volume2B, 253667-084US, June2024](https://cdrdv2-public.intel.com/825757/253667-sdm-vol-2b.pdf), MAXSD/MINSD operation and description (PDF pages19/30, zero-based as reviewed by the coordinator). These editions are identified, not claimed latest. Equal finite operands, including opposite signed zeros, select the second source. Neither clamp exercises MINSD/MAXSD NaN behavior because both operands are finite.
