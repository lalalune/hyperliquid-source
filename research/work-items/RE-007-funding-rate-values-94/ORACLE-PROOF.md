# Independent exact value oracle

`oracle.py` is written before production, contains no decoder or native evaluator, imports no candidate implementation, and uses no host floating arithmetic. Its expected corpus is a mathematical consequence of the manually recovered operation sequence under the explicit Intel SSE premises. It is not measured captured output.

For any finite raw binary64 encoding, `rational` constructs the exact signed `Fraction` from its integer significand and power of two. The subnormal exponent is -1074; a normal exponent is encoded exponent minus1075 and its implicit significand bit is included. Zero signs are handled separately by the operation, because the rational number zero has only one signless value.

`rounded` works on an exact nonzero rational magnitude. At or above `2^1024-2^970` it selects infinity, the nearest-even overflow result. Between the largest finite value and that midpoint it selects the largest finite value. Else it binary-searches monotonically ordered positive finite encodings for two adjacent representations bracketing the exact magnitude. Exact rational distances select the nearer one; equal distances select an even low significand bit. This also covers the zero/minimum-subnormal midpoint and the subnormal/normal boundary. The original mathematical sign is then restored, including an underflowed negative zero. Binary search and Fraction distance are intentionally different from the planned integer significand/sticky-bit production.

Arithmetic class rules run before rational arithmetic. NaN selection respects first-source priority, signaling quieting and original sign/payload. Subtraction checks for NaNs before negating the second finite/infinite operand. Invalid non-NaN operations produce the documented indefinite. Infinity and zero signs follow the explicit operation rule. Additive cancellation is positive zero except two negative zeros; multiplication/division use XOR signs. Only finite values enter the raw operand-select clamps; comparisons use exact rational order and equality selects the second argument.

The ordered sample fold has a negative-zero seed and no reassociation. The positive length is exactly rounded before division. Gap subtraction, each finite classification, both operand-select clamps, corrected-mean addition, multiplier and final one-eighth multiplication remain separate rounded steps. An absent or empty sample sequence returns no active raw value. Output contains both that optional result and the caller's absence-to-positive-zero projection, preserving present NaN, infinity and either zero sign.

The corpus includes missing/present-empty distinctions; sample/parameter normal, subnormal, signed-zero, infinity and signed signaling/quiet NaN classes; all ordered pairs of34 selected classes; loop lengths around8/16/32/64; class placement at first/middle/last; cancellation and NaN-priority order witnesses; exact clamp boundaries; each optional parameter separately; deterministic full-width bit patterns. Semantic labels are retained only in a separate provenance file. They never enter the later client.

Seventeen direct mathematical checks independently pin subnormal and overflow midpoints, minimum-normal ties, cancellation/zero signs, NaN selection/quieting, invalid arithmetic and the clamp signed-zero witness. They are oracle sanity checks, not evidence that all generic floating operations are native public APIs. The 3,153 end-to-end cases are finite evidence, not exhaustive coverage of all raw sample sequences. The general claim also depends on the manual native proof and a later complete production-algorithm argument.
