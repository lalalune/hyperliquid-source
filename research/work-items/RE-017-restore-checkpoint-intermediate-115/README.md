# RE-017 · Restore checkpoint admission and row order

Target Linux x86-64 Node #115 SHA-256 a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301. The [local restore packet](../RE-017-local-state-restore-115/README.md) identifies caller 0x2cc15de, intermediate 0x25d3f20, and the caller's sentinel fallback. This packet follows the selected directory gate and the order of records consumed inside that intermediate.

On the selected entry path, 0x25d3f62 references the format fragment `/checkpoint`. The formatted pointer and length go to directory-test slot 0x64e0928 at 0x25d3f95. Zero AL branches to the format fragment `checkpoint outer dir does not exist` at 0x433a07 and calls 0x2a02000 with the formatted result. After the optional temporary release, a zero global word at 0x64f01d8 selects 0x25d409d. That arm stores 0x8000000000000000 at output offset zero and invokes the first slot of the returned object's table. This links the selected directory-test failure to the previously observed caller fallback. The message identifies the branch. It does not distinguish a missing directory from a failed metadata lookup.

The other selected path reaches 0x25d410d and reads the returned count and pointer from stack offsets 0xa0 and 0x98. For a nonempty buffer, the reversal loop takes the left offset from zero and the right offset from 24×count−24. It exchanges the three consecutive words at offsets 0, 8 and 16, moves both offsets inward by 24, and stops after floor(count/2) swaps. A one-record buffer skips the loop. The following scan advances its pointer by 24 from the beginning of this same buffer. These observations determine order relative to the returned buffer. The upstream enumeration order, sorting criteria inside the producer, and the final selection of a restored checkpoint remain open.

The per-row scan passes the component returned by 0x25fa9c0 at 0x25d4281 into an unsigned decimal gate. A missing or empty component and isolated signs skip the row. One leading ASCII plus is removed. Each remaining byte must be an ASCII digit. Below 17 digits the loop uses unchecked multiply-add by ten, whose maximum result fits in u64. At 17 or more digits the loop checks multiplication overflow and addition carry separately. Invalid input and overflow resume at the next 24-byte row. The 17-digit boundary selects the arithmetic loop, so leading zeros can allow a longer component.

On the parsed path the first regular-file-shaped test is at 0x25d43c6. A false result tries another constructed path, with argument 2 to 0x1696b90, and the same predicate at 0x25d4428. If either predicate is true, the selected normal allocation path appends a 32-byte record with the numeric value at offset 24. With both predicates false and both global checks zero, the other vector receives the address of the original 24-byte row. This is the observed partition before checkpoint selection. The exact filesystem meaning of argument 2 and the handling of the second vector after collection are open.
