## Selector and copy

The copy IS a Duff's-device loop (0x6398f08..0x6399027), but it is FULLY DEAD. The length is *r8 (`mov (%r14),%rdx` at 0x6398e91, r14 = entry r8); if the length is exactly 8, the qword from the stack temp (%rsp) is stored whole to *rcx (`mov %rsi,(%r12)` at 0x6398e9a) and the window exits 0 (`xor %ebp,%ebp` at 0x6398e9e).
