# Conditional contracts and memory assumptions

These are static local relations, not general memory safety or original Rust provenance.

1. Reached callbacks return normally and preserve the callee-save registers, stack and protected control/saved-argument slots. Unwinding, faults, nonreturn and concurrent mutation are outside scope. The helper's saved incoming data/descriptor survive to their reloads. No original Rust ownership or ABI discipline is inferred from this condition.
2. Actually accessed memory is valid at the time reached. The prior-error field path does not need a usable formatter/name/value because it does not access them. Other paths need their actual destination/method/name/value accesses. Observed state/frame footprints are not nominal Rust size, alignment or type claims.
3. For nonsticky field paths, sampled H is 0 or 1; sampled byte(F+0x12)&0x80 selects flat/pretty. The pretty branch uses the earlier sampled mode bit even if the opening callback later changes F. Its A/L contents are sampled after that callback. These are temporal observations, not assumed unchanged F values.
4. The adapter's finite input bytes remain unchanged during an invocation, with no relevant address/length wrapping. Protocol flag or callback writes must not corrupt the input, protected frames/control state or later-needed metadata. A must be readable even with zero input length; the zero-length route does not dereference input bytes or the flag pointer.
5. Cached D/V/B mean values at the actual post-prologue loads. They are not assumed pre-prologue memory contents. The protocol flag must be separated from all adapter prologue/private-frame/saved/return writes when inferring its physical preservation. Empty input means no B-directed protocol access; it does not mean the machine made no other memory writes. For the actual parent's direct adapter calls, observed stack equations place its N at adapter RBP+87 above those intervals. Nested calls retain the explicit stack/alias conditions.
6. Primitive call facts use cached pointer values but freshly loaded method entries; stable writer identity needs separate method-slot preservation. To infer a final physical flag value, writer callbacks must preserve that flag. Otherwise the contract states only the ordered pre-callback store. Callback mutations and alias effects beyond these conditions remain unknown.
7. The pretty value callback receives local L and may update N through the adapter protocol. Every callback capable of reaching A/L must preserve the metadata needed for the known suffix-adapter specialization. The suffix actually reloads L's destination/vtable; no unchanged-target assumption is implicit. The original F and local L are observed native records, not recovered Rust Formatter or trait types.
8. Writer branches test raw AL zero/nonzero. Earlier field errors become byte 1, while flat value AL is propagated without a test. The adapter's normal failure writes AL=1 only; higher RAX bits and original bool/enum/Result layouts are not qualified.
9. The scan proof uses static operand/CFG relations, interval inequalities and a byte-borrow lemma. Finite test vectors corroborate the tooling; they are not captured instruction/callback execution, an instruction interpreter or runtime equivalence. Physical rendering, arbitrary aliases/clobbers, application reachability, complete original types/callbacks and source equivalence remain unqualified. No component gate or new Rust component is claimed.
