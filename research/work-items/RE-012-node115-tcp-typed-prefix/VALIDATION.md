## Reproduce

Use a reviewed Python installation and an installed GNU objdump. From the repository root, choose fresh output directories; the captured input is read as data only:

```sh
python3 -I -B -S research/work-items/RE-012-node115-tcp-typed-prefix/collect.py --target artifacts/node/115/hl-node --objdump /path/to/gnu/objdump --output /tmp/tcp-prefix-one --check research/work-items/RE-012-node115-tcp-typed-prefix/observed
python3 -I -B -S research/work-items/RE-012-node115-tcp-typed-prefix/collect.py --target artifacts/node/115/hl-node --objdump /path/to/gnu/objdump --output /tmp/tcp-prefix-two --check /tmp/tcp-prefix-one
python3 -I -B -S research/work-items/RE-012-node115-tcp-typed-prefix/controls.py --target artifacts/node/115/hl-node --evidence /tmp/tcp-prefix-one --output /tmp/tcp-prefix-controls
python3 -I -B -O -S research/work-items/RE-012-node115-tcp-typed-prefix/controls.py --target artifacts/node/115/hl-node --evidence /tmp/tcp-prefix-one --output /tmp/tcp-prefix-controls-optimized
```

Expected result: each command exits 0; replay reports 14 exact native files and equal semantic records; each control run reports 96 passed, including 44 semantic-byte controls. The public sources are byte-identical to the qualified private sources. These commands are reproduction instructions, distinct from the exact observed argv receipts.
