# Production plan after the pre-code gate

No production Rust or input client exists in this phase. The proposed real crate is `src/visor-duration-value`, with one package, no dependencies, no build hooks and no parent/root workspace. The later source freeze must bind its actual manifest/lock, API, tests, input-only client, build harness and admitted installed toolchain before compilation.

Implement the contract using raw-bit classification and bounded u128 arithmetic. For positive ordinary inputs, obtain M/e from the encoding, multiply M by1e9 once, and adjust the binary scale with exact integer shifts. Use quotient/remainder and an even-parity tie decision before splitting total nanoseconds by1e9. This unified significand calculation differs from the native two fractional regimes and from the oracle's exact Fraction distances. Products stay below2^94; admitted right shifts are bounded after the proved tiny-input zero case. No host floating operation, libc conversion, generic software-float package or native code translation is needed.

For positive fallback inputs use the independently proved ordered raw-bit overflow boundary, then the exact u64::MAX microsecond quotient/remainder. Negative/nonfinite/zero inputs producezero. The constant threshold must be tied to the frozen inequality certificate, not guessed from a successful finite fixture. API names/private fields are fixed in `CONTRACT.md`; the original ABI is unclaimed.

Later qualification must run the real compiled crate and input-only client with the unchanged independent expected corpus, in debug/release and two fresh isolated directories. Planned semantic mutants cover each of the13 wrong-model families plus source-specific branch/rounding mistakes, and must compile and emit complete differing outputs. Malformed-client and comparator controls must demonstrate actual rejection. Full toolchain/config/ancestor-workspace/dependency admission and raw artifact/log preservation are mandatory. Byte-different compiled outputs are retained and reported without masks or an assumed cause. Source, actual builds and publication remain separate later gates.
