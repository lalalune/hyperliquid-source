# RE-009: selected snapshot item consumer index relation

Target Linux x86-64 node #115 `artifacts/node/115/hl-node`, SHA-256 `a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301`. [#7118](https://github.com/lalalune/hyperliquid-source/pull/7118) connects a selected snapshot worker's 16-byte entry to calls `0x2c6f0b0` and `0x2c6ecb0`, leaving their internal branches open. The existing `RE-001-node115-books-selected-broadcast` proves the same multiply-high constant's u64 division relation in a different caller; the location-edge packets for the two functions cover their distinct tag-1 edges. This packet follows their selected non-1 branches to the shared state row.

Both callees compare the entry's first qword with 1. When it is not 1, the second qword N is multiplied unsigned by `0x346dc5d63886594b`, the high half is shifted right by 11, and the resulting Q is compared unsigned with state `+0x7d0`. The prior arithmetic proof identifies Q as `floor(N/10000)` over the u64 domain. If Q is in range, each uses state `+0x7c8 + Q*0x510` as a row address, subject to valid arithmetic and storage. The second consumer calls `0x276e1a0` before its bounds comparison; an out-of-range path is not a clean success.

For the first consumer, the selected in-range path additionally compares row `+0x50` with Q, calculates R = N - Q*10000 and compares R with row `+0x10`. With equality at the first check and R in range it indexes 32-byte entries through row `+8`; the selected nonempty entry supplies pointer/length to a new allocation and copy. The mismatched-row, out-of-range remainder and zero-length paths select a zero-length result with a non-null sentinel. Allocation failure and diagnostics are separate. The other consumer passes the selected row and its prior helper result to `0x23dcd80`; its body remains a boundary.

These observations are conditional on #7118's selected call sites, the tag-not-1 branch, valid non-overflowing buffers and normal helper/allocator returns. They do not establish the original row types, actual item provenance, live scheduling, output correctness or checkpoint/root equivalence. No captured target executes and no component gate changes.
