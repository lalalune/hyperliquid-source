# Pre-code plan and later build admission

The current phase contains static target binding, a manual conditional proof, independent mathematical expectations and a protocol only. Rust writing requires the root reviewer's separate pre-code gate. Original pre-code files, manifests, receipts and freeze must remain immutable after that gate. A later source/harness freeze and additive implementation manifest will preserve chronology.

`collect.py` authenticates the complete Visor, two existing main evidence files, eight complete body byte ranges, raw FDE/CIE records, 438 operand anchors, five literals/tables, 54 calls and all15,595 RELA writers. GNU and LLVM independently decode and must tile all3,866 bytes with the same910 raw instruction partitions. All complete exports are retained as deterministic gzip; compact records retain providers, exact commands and all scope/call bindings. The two dynamic context calls and cold callees remain explicit unknowns. No normalization or original-compiler identity is claimed.

`arithmetic.py` checks whole-interval reciprocal inequalities and complete finite domains:146,097 calendar-cycle days,524,286 admitted signed years and86,400 ordinary seconds. It independently checks captured table bytes against Gregorian divisibility/counts. This is arithmetic on formulas, never an instruction evaluator. `PROOF.md` supplies the indispensable native-to-formula, path, frame and preservation argument. The certificate does not establish opaque helper behavior.

`corpus.py` uses whole Gregorian day counts, a binary-search year inverse and whole integer-nanosecond addition/clamping. It does not import the native binder or algebra, copy inferred code, use target instructions, call a clock or read a library date implementation. The current deterministic corpus has60,009 cases:12,764 successful sample constructors,20,324 successful parts admissions,19,536 deadlines,7,330 comparisons and55 newly chosen safe refusals. All400 year residues, negative-year corrections, leap/century boundaries, epoch, range ends, fixed60 rollover, equal/before/after comparisons and ordinary nano ends are represented. This finite corpus supplements the proof; it is not exhaustive over all timestamps.

`verify.py` replays native, algebra and corpus generation into two fresh directories and compares every output byte. It tests changed target identity separately from below-identity anchor/literal/call/FDE/RELA checks. Repinned FDE fields and call operands must still fail their structural relation. Algebra mutants execute only changed copies of this packet's own mathematical expressions. They are not captured execution or a native instruction simulator. Frozen receipt control names state the exact rejection layer; no semantic mutation claim is made for byte anchors.

After the gate, the proposed crate is dependency-free, standalone and real: one library manifest, a genuine Cargo lock generated by the pinned Cargo, public value API, README and focused value tests. It has no root workspace, build script, proc macro, FFI, dynamic dependency, filesystem/clock/shell/network action or dependency stub. No raw arbitrary-date constructor is exposed. Candidate calendar inversion should use independently authored bounded cycle/carry arithmetic, distinct from the oracle's whole-day binary search. Its ordinary failure policy is explicit `Option`, not a guessed native error ABI.
