## Domain, external return and storage

Define `leap(y)` by divisibility by 4 except centuries not divisible by 400, for mathematical integer years. Define `L[r]` as the number of leap years in `[0,r)`, for `0<=r<=400`; define `F[r]=(leap(r)?0:8)|((365*r+L[r]+3) mod7+1)` for `0<=r<400`. Modulo is Euclidean. The exact bytes at `0x7d692` (401 entries) and `0x7d823` (400 entries) equal these formulas. No absolute weekday names or source-library identity are needed.

A canonical timestamp has packed date `p(y,o)=8192*y+16*o+F[y mod400]`, year `-262143<=y<=262142`, ordinal `1<=o<=365+leap(y)`, second `0<=s<86400` and nano `0<=n<1000000000`. Date packing lies in signed32 range; the positive low part is below8192. A zero date word cannot be canonical. This domain is an explicit premise at the readiness source/current comparison, not something proved from an arbitrary nonzero word.

For the new sample constructor additionally admit numeric sample seconds `0<=z<=8210266876799` and unsigned nanoseconds `0<=n<1000000000`. The imported function reached by the primitive returns normally with its EAX different from `0xffffffff` and writes those two qwords into its passed 16-byte buffer. Its actual ELF slot and symbol are bound; an actual runtime loader, syscall, live clock, elapsed-time semantics or non-interposition guarantee is not inferred. The numeric call argument is zero. All code, tables, slots and input/sample storage are stable, ordinary nonvolatile memory, and the admitted calls preserve the stated caller storage and callee-saved state.

At entry to `444600` let RSP=S and output pointer=O. Require a nonwrapping writable12-byte output disjoint from all reached live frames, immutable image and inputs. S mod16=8, and the return word `[S,S+8)` and all saved-register/temporary stack accesses are valid. Four pushes and `sub rsp,0x38` give local base B=S-88, aligned16. The difference result is at `[B,B+20)`, saved sample at `[B+24,B+36)` and zero reference at `[B+40,B+52)`. These regions are distinct. The primitive and admitted nonrecursive difference each use local storage down to B-48; the primitive's external call adds a return slot at `[B-56,B-48)`. The external callee's own stack requirements are a separate ordinary-call premise, not bounded by the local export. The day constructor uses its return slot and one extra eight-byte push below B. No claim initializes padding between the specified stores.

For the readiness arithmetic separately require execution at `5b4369`, a stable readable source triple through R15, and the shown distinct caller copies/time result/current triple at stack offsets `+0x88..+0x94`, `+0x28..+0x38` and `0..+0xc`. This is a selected value corridor, not whole-function readiness reachability.

## Deliberate limits

The safe sample/parts refusal is newly chosen policy. Native negative samples, invalid fractions, import failure, out-of-range constructor input, generic duration/date/time operations, arbitrary packed words and error-object/panic/unwind behavior remain outside the successful value projection. The old extended-input counterexample remains valid: at the fallback date/second, raw nano1000000000 compares greater than fallback nano999999999. The ordinary maximum and safe type must not silently admit it.

Complete native exports and raw FDE/CIE/call/data/RELA bindings establish scope and operands. An FDE alone does not prove all possible incoming references or ownership. Arithmetic certificates concern mathematical expressions and finite calendar classes, never a register/PC/flag interpreter. The manual address-to-formula argument is indispensable. No captured target or instruction evaluator executes, and host Rust matching will not prove an original compiler, target byte identity, elapsed-time behavior or complete readiness policy.
