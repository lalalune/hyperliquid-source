# RE-009: selected snapshot empty-index insertion

This packet follows the absent-root case of the selected snapshot sink's lookup from [#7129](https://github.com/lalalune/hyperliquid-source/pull/7129). At `0x2dc3525..0x2dc352c`, a zero root pointer takes the path into the insertion handoff. With a normal, nonsentinel key descriptor, the sink copies the 72-byte input payload to a temporary, constructs a descriptor containing the root slot and zero root, and calls `0x26dcf60` at `0x2dc37a2`.

For a zero root field, that helper requests a `0x430`-byte allocation and checks for failure. On a nonnull allocation, it initializes the first qword and the 16-bit count at `+0x42a` to zero, installs the root pointer, and stores the three key qwords at `+0x08`, `+0x10`, `+0x18`. The old count is zero on this newly allocated path; it increments the count to one and copies the 72-byte payload to node `+0x110`. It increments the owning object's counter at `+0x10`. Failure takes a separate call at `0x26dd0f9` and does not follow the successful initialization path. Nonzero roots go through another helper and are outside this packet.

These observations are conditional on the selected caller, valid independent input buffers, allocator success and ordinary control flow. The root's higher-level identity, key semantics, persistence and real checkpoint/root equality remain open.
