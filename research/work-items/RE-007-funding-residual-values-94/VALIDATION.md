# Pre-code validation

The retained validation/pre-freeze.json is the byte-exact result of both actual
normal and `python3 -O` runs listed in validation/runs.json. Each regenerated
all retained native exports, complete records, independent corpus and certificates
in two fresh trees and compared every output byte. Each passed110 rejection
controls. A frozen replay also rehashes every PRE-RUST-FREEZE entry first.

The controls comprise wrong identity/size/scope/provider census,88 real changed
instruction cases,6 raw relocation changes,2 raw FDE changes,2 hash-constant
changes, and4 independent fresh-decoded CFG bypasses. Instruction controls run
full GNU/LLVM decoding of the changed owning FDE below target/body hash gates.
They reject changed proof bindings, not demonstrate target runtime behavior.
CFG controls omit byte pins and directly challenge the nonvacuous order facts.

The independent corpus contains912 cases:853 under the native conditional
domain and59 for new safe-policy admission. The input and complete expected
frames were produced before any source/client/build harness. Opaque IDs carry
no semantic/expected hints. Native values are modeled by flat sorted relations,
arbitrary-precision clamp and the algebraically closed auxiliary relation.
Examples are finite; universal claims rely on the explicit manual proof and
premises. The certificate adds36 symbolic full split gaps,66 nonfull insertion
gaps,32,768 exhaustive width8 auxiliary cases and1,126 i64 threshold checks.
It evaluates no captured instructions or physical native tree.

The initial static collector draft used an incorrect auxiliary occupied-return
address in its own CFG obligation and rejected the original bytes. That draft
obligation was corrected to actual RET33bc551 before these final runs/freeze.
An early negative-control label/index was also corrected so the shortened-FDE
control edits the named main range. Neither changed the native relation,
independent corpus or source (none exists), and neither is counted as a
successful target mutation detection. Draft run logs remain in the research
session; the public result here is the final qualified static checker.

The only imported repository code is the two hash-pinned baseline static
ELF/DWARF parsers in dependencies.json. Copy/export methodology is locally
adapted from author-owned MIT prior work, with exact credit, and has no runtime
pending-PR dependency. Native provider versions/hashes are retained; no full
hermetic provider/runtime claim is made. Full code/data raw byte partitions,
FDE/CIE records and RELAs are re-admitted from the capture for each replay.

No Rust source/client/build harness, captured executable or instruction emulator,
full repository test suite, benchmark, live service, networked node, economic
oracle, scheduler proof or production completion was used or claimed. Ordinary
external memory frames, worker provenance and selected-state existence remain
premises. Safe rejection before mutation is prospective API policy, not native
panic rollback. Source authoring and compilation need their own later gates.
