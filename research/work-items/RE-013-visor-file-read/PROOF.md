The grammar is independently specified by [RFC3629 section4](https://www.rfc-editor.org/rfc/rfc3629.html#section-4). On any high bit the scalar loop resumes at the same not-yet-consumed position; a multibyte branch advances exactly its admitted width. The invariant is that every byte below cursor belongs to complete accepted scalars, and cursor points to the next sequence start. Finite inputs terminate because successful scalar steps advance1..4 bytes.
