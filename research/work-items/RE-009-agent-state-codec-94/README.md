# RE-009: AgentTracker snapshot field decisions

The node #94 AgentTracker snapshot has five ordered fields, but its selected JSON map reader requires only the first and third and constructs defaults for the other three, allowing a reconstruction to preserve older partial state representations and duplicate-field rejection.

- Component ID: RE-009, storage and state snapshots.
- Target release and full SHA-256: Linux x86-64 node #94, `3b7179cd967d1b13b683e05debfc685ad4c750e918226402d5d575eff1c0459f`.
- Source commit / reference commit: repository `56c0ec672bd8fdcfaa80f2db700a61e6240b3663`; inferred and unlicensed reference `999556f6e0a474b8312db96ec3149e1c44e97c23` was used only as a lead.
- Claim status: observations are the named bytes, selected calls, branch targets and unwind extents; the correspondence between independently found reader and writers and the state-field interpretation are inferences. Full child-value grammars remain unresolved.
- Scope included and excluded: the selected JSON field classifier and map decisions, the positional decisions of one MessagePack-shaped reader, two writer forms and their immediate error exits. The enclosing Exchange reader is contextual; child container and element codecs, actual snapshot selection, other releases, execution and network access are excluded.

### Positional reader and writers

The selected MessagePack-shaped sequence reader checks count and child results in order. Conditional on prior child successes, count 0 reaches a short-sequence route, and counts 1 or 2 reach the route carrying missing index 2. Count 1 initializes the second value before the missing-third route. Count 3 initializes the fourth and fifth values, count 4 initializes the fifth, and count 5 reaches the five-value join. Counts greater than 5 pass an excess count to a downstream helper; its complete behavior is not claimed. `sequence.tsv` is a model of these selected branches, not a set of executed inputs. The two leading map requirements and the positional checks are separate observations, not a proof of identical format grammars.

The MessagePack-shaped writer selects a five-entry map-header helper when serializer byte `+0xb` is 1, and a five-entry array-header helper when it is 0. In named mode it emits the five field names before their respective child calls; positional mode omits those names. For each field a failed name write and a failed child result branch to separate common exits (`0x230d36c` and `0x230d37b`); the table records all child targets. Serializer-byte values other than 0 and 1 are outside this interpretation. The JSON-shaped writer opens an object and calls writers for the same names and offsets in order; its fifth field is emitted by the separately bounded helper. The selected value-call failures stop the following stages. The full JSON byte stream and the value codecs are not reconstructed here.
