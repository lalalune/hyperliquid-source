Component: foundation; task RE-012. Sole target Linux x86-64 node #115,
105,896,032 bytes, SHA-256
`a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301`.
Base `05bc2de303c05525b71e7e257426e741bc66a390`; original ELF VAs,

New project-authored static research and scripts are MIT.

## Question and result

How does `0x5c8f4c0..0x5c902df` create missing parents, distinguish error
classes, preserve failures and order later attempts? What does its option
byte change?

The base configuration-path research records three direct `mkdir`-bound
calls, the mode word and an error integer, but explicitly leaves creation
internals open. The earlier temporary-path factory packet likewise keeps
this helper as context. This result resolves the selected routine's complete
creation-policy flow: a **two-phase iterative parent search and reverse
replay**, not function self-recursion; short/long C-string conversion; actual
error-kind tables; already-existing-directory checks; and error/vector cleanup.

Fresh live open PR titles inspected on 2026-11-04 showed the factory and
component/UTF-8 work but no competing recursive-creation outcome. No issue was
opened, drafted or claimed. Existing exported helper windows gain no new
byte-equality credit. This is static research; supplying invented syscall or
allocator stubs as Rust would not establish the missing runtime behavior.

## Inputs and one-attempt operation

Entry RDI points at options: a mode dword at +0 and option byte at +4.
RSI/RDX are the raw path pointer/byte length. `CMP [options+4],0` at
`0x5c8f4da` selects the one-attempt arm only for zero; any nonzero byte selects
the parent-creating policy. The original mode dword is passed to `mkdir`
without a new mask here. The caller's 0777 value does not prove final
permissions after the operating system's umask or other effects.

Every individual attempt has the same relevant normal outcomes:

* If the path is at most **383 bytes**, copy it into the 384-byte stack
  region and append zero at offset length. Scalar/word scans locate zero;
  a first zero exactly at the appended position admits the call. An earlier
  zero rejects the path without calling `mkdir`.
* Longer paths call `0x5c78ed0..0x5c78f6f` with callback `0x5c81110`.
  Slot `0x64df718` resolves to `0x141e960..0x141eada`, which allocates
  length+1, copies the bytes and checks for interior NUL. Its success path
  calls `0x64df690` -> `0x141e170..0x141e251`, appending the terminator and
  returning the owned pointer/length including that terminator. The adapter
  invokes the concrete callback, clears the first byte and releases the
  temporary owned C string on normal and selected unwind paths.
* The callback `0x5c81110..0x5c81140` obtains the options' mode dword and
  calls imported `mkdir`. Main short-path sites do the same call directly.
  A return other than -1 becomes zero (success). On -1, imported
  `__errno_location` supplies a dword, encoded as **(u32 errno << 32) | 2**.
* Interior NUL returns static error pointer `0x64c2fb8`, whose kind byte at
  +0x10 is 20. Long-path conversion failure uses that same pointer and
  releases any allocated failed conversion buffer. Allocation, valid slice
  bounds and exception behavior remain explicit helper/runtime boundaries.

This policy is byte based; no UTF-8 validation is inserted in the selected
creation/conversion paths. The actual imported symbols `mkdir`, `stat64`,
`__errno_location`, `memcpy` and `bcmp` are resolved from dynamic symbol
records and relocation writers, not guessed from slot names.

## Option zero: single attempt

`0x5c8fbae` performs just the operation above with the original path. It
returns its error unchanged, including error integer 17; it does not perform
the recursive arm's metadata-based acceptance. An empty path also reaches
that single attempt. There is no error-integer-4 retry in the mkdir callback
or this arm. Actual syscall outcomes are not generated by this research.

## Nonzero option: upward search

The nonzero arm returns zero immediately for an empty input. It builds Unix
component cursors with prefix sentinel 6, front/back states 1/2, and an
absolute flag from a nonempty first byte `/`. The complete cursor, remaining
view and component equality contexts are exported and their real bindings
retained. Equality against an empty component sequence and last-component
classification provide the empty/root stopping boundaries. A final root or
none component is outside the `(tag+0xf9) mod 256 < 3` admission, so the root
boundary does not issue another `mkdir`.

For an admitted path, the upward loop at `0x5c8f710` computes its next parent
view, then attempts the **current full byte pair**. Preparing a parent view
does not mutate or replace the current attempt's source pair. The routine
starts a missing-prefix count at zero. After an attempt:

| Selected result | Upward action |
| --- | --- |
| Zero | Stop climbing and proceed to replay the counted descendants |
| Kind 0 | Destroy this error, increment the missing-prefix count, select the parent pair and continue if present |
| Kind 12 and metadata says directory | Destroy the create error, stop climbing and proceed to replay |
| Kind 12 with failed metadata or non-directory mode | Return the original create error; dispose of any metadata error |
| Any other kind | Return the original create error |

The error-representation dispatches at `0x948184` and `0x948194` each have
four signed-relative entries selected by the error word's low two bits.
They support static-message, boxed-message, native-error and embedded-kind
representations. Concrete mkdir errors normally use native representation 2;
interior-NUL errors use the static-message representation. The other generic
branches are retained as conditional representation behavior, not fabricated
syscall outcomes.

Native errno classification is the complete FDE `0x5ca1930..0x5ca19b9`.
Its 122-entry signed-relative table starts at `0x948920`, indexed by errno-1.
All destinations are actual instruction boundaries with constant-return
leaves. The retained `errno-kinds.tsv` records every entry. In particular:

| Error integer | Observed kind | Creation consequence |
| ---: | ---: | --- |
| 2 | 0 | Climb to a parent |
| 17 | 12 | Check whether the same path is now a directory |
| 4 | 35 | Return error; no same-path interrupt retry |

Out-of-table native integers select default kind 41. The numeric relations
are target observations; no current host errno behavior is substituted.
The generic embedded-kind representation clamps to 42 as shown in the
retained operands. Imported functions may be interposed; the static policy
is conditional on the declared call/representation contract.

The AlreadyExists-like check is deliberately narrow: it is not “swallow any
mkdir error if stat happens to say directory.” Only kind 12 reaches metadata.
Slot `0x64e0930` binds to `0x5c9c810..0x5c9ca28`, including `stat64`.
A metadata error tag 2 is disposed while retaining the original create error.
A non-error mode at result+0x38 is accepted only when
`(mode & 0xf000) == 0x4000`. Race freedom, symlink guarantees and durable
filesystem effects are not established by the existence of that check.

## Prefix collection and parent-first replay

After the upward stopping boundary, the routine knows how many NotFound-kind
attempts were discarded. At `0x5c8fdd3` it checks allocation arithmetic for
**count * 16**, allocates a vector, and walks again from the original target.
Each 16-byte entry is the current `(path pointer, byte length)` followed by
selection of its parent. The local vector has capacity at `rbp-0xe0`, pointer
at `rbp-0xd8` (also retained at `rbp-0x30`) and entry count at `rbp-0xd0`.
Its growth call remains an allocator/reserve helper boundary; it is not
replaced by a fictitious recovered workspace dependency.

The replay loads records from the vector's end, then subtracts 16 at
`0x5c8ffe0`. Thus missing ancestors are attempted before their descendants.
For example, when the upward search discarded the attempts for `a/b` and
`a`, the collected order is [`a/b`, `a`] and the replay order is [`a`, `a/b`].
This is a consequence of actual pointer/length stores and reverse loads,
not an executed filesystem trace or a claim that a particular directory
existed on the user's computer.

Each replay attempt uses the same short/long path conversion and original
mode. Zero proceeds to the next record. A nonzero error is accepted only
for kind 12 plus a successful directory metadata check. Accepted errors are
destroyed; a failed stat is destroyed while the mkdir error is preserved.
Any unaccepted error releases the vector and returns that original error.
After all records, vector release precedes the shared zero-success return.
Landing pads retain the corresponding error/vector cleanup before unwinding.

There is no direct recursive call to this same FDE in the retained call
inventory. “Recursive” describes creation of parent directories, implemented
by the bounded cursor/count/vector/replay loops. It does not establish that
all external callees terminate or that malformed native object layouts are
safe inputs.

routine, long-path adapter and mkdir callback, CString constructor/finalizer,
errno-kind helper, metadata helper, error destructor, component comparator,
reverse component iterator and remaining view. Export counts are not
reconstructed bytes or additional credit for shared helper windows.

`records.json` binds exact body hashes, actual FDE/CIE bytes and LSDA addresses,
101 calls, 309 direct/dynamic branches, relative/helper bindings, five dynamic

representation tables, 122 errno entries and six component-prefix entries).
Every resolved target is an instruction boundary. Unexamined allocator/reserve
calls and dynamic edges remain explicit rather than being called a fully
closed whole-program CFG.

readelf independently confirms all extents. Only LLVM's separate LOCK prefix
row is joined to its contiguous instruction. No bytes are normalized.
`tools.json` retains actual versions; collector commands retain options.

## Remaining boundaries

was run. No Rust implementation, peer runtime, hosted CI or container result
is claimed. The OS, imported-call interposition, pointer/layout validity,
allocator/reserve behavior, generic error-trait destruction, complete cursor

observed creation policy under those contracts, not a complete filesystem or
node. All 92 component gates and registered byte-comparison totals stay
