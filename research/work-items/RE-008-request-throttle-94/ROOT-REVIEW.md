# Independent request-throttle review and qualification

The contribution adds the complete retained request-row supplied-state operation
to the existing dependency-free consensus-admission crate. Exact unsigned
round/hash keys, original timestamps, reason union, inclusive deadlines and
one-shot emission are preserved. The new map is separate from existing block
admission's tag-zero removal context. Earlier PR951's outline and PR1473's date
work are credited; no unmerged implementation is a runtime dependency.

The52-file pre-code packet, source freeze and all original author phase files
remain unchanged. Root actual pre-code replay passed91 controls and two complete
regenerations. Its only difference from the author's pre-freeze receipt is the
explicit final-freeze hash field. Root independently bound12 full FDEs,
28005 bytes/5595 rows,80300 relocations,62 slots,315 calls,294 RIP references,
642 references,2362 instruction pins and10 data spans. Full semantic reading
covered9 subject/helper bodies and five caller argument/result windows; no
complete semantic proof of all three enclosing caller bodies is claimed.

The native map/set insertion and calendar/delay relation have full conditional
proofs. The new source uses an integer83-bit product and53-bit ties-even rounding,
overflow-to-zero before signed saturation, and a closed Gregorian bridge. Root
read the full new source/client/proof/harness and independently checked524287
year starts against a400-year cycle construction. Separate peer mathematical
replays matched all949 frozen histories/3776 steps. The frozen delays contain
no exact multiplication-halfway input; universal ties-even correspondence rests
on the source proof, not on finite mutant coverage.

Root and peer caught a pre-compilation harness admission defect: Python tuple
edit pairs did not compare equal to JSON list pairs. The original builder and
source freeze remain immutable. The separately reviewed additive amendment
changes that comparison to canonical JSON and binds original/new identities
before and after execution. It changes no source, client, corpus or mutant
meaning. The original builder main was never run; no failed Cargo run is
reclassified as a semantic kill. Use `build-amended.py` as documented in
`source-validation/IMPLEMENTATION.md`.

After the exact amended build gate, author and root each completed174 commands:
153 exit0 and21 intentional exit2 refusals. In each profile,38 library tests
(36 existing plus2 new) and8 new integration tests passed. Four normal streams
per run match all949 histories. Eighteen compiled native mutants change native
histories; two policy mutants change only new-policy histories, in both profiles.
All44 complete streams agree across author and root. Ten comparator controls,
20 malformed batches, an extra argument and valid empty input were checked.

Root rehashed696 raw child-stream references,176 retained first-compiled
artifacts,44 source copies and44 clients across both runs. Between distinct build
paths, rlibs and release clients match while debug clients differ. Across
corresponding root/author artifact identities,66 of88 match. These comparisons
use no masks or normalization and establish no cause of the debug inequality.
Compiled bytes remain private; public hashes do not imply public availability.

`ROOT-COMPARISON.json` records actual results. `root-validation/` retains root
commands, exact child streams, full post-source static result, graph/artifact
identities and historical review/gate records. Any logical projection of private
review-path metadata is explicitly marked with the original hash. Archive gzip
locations may reuse identical author bytes; original root command metadata is
also retained. Raw child output and compiled comparisons are never redacted.

InvalidTime is a new pre-mutation refusal; DeadlineRange is a new refusal after
registration/reason insertion. Native panic/unwind, allocator/lock/log/network
effects, row pruning/reset and whole consensus scheduling are not implemented.
Successful allocation, valid native state, normal helper returns and explicit
noninterference/float-environment premises remain required. The captured target
was not executed or instruction-evaluated; old evidence_contract and broad tests
were excluded. The complete contribution is bound by PUBLIC-MANIFEST.json.

The immutable `source-validation/build-amendment.patch` is exactly the unified
diff between the two frozen builder files. Its two blank context lines contain
the required single-space diff prefix. A root-owned nested `.gitattributes`
disables only blank-at-EOL checking for this exact patch path; other paths and
whitespace checks retain their defaults. The patch and all historical freezes
remain byte-identical.
