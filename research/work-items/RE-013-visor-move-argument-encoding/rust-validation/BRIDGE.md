# Safe Rust bridge to the proved value relation

The library is independently authored MIT Rust. Its public contract is the separately approved and frozen `pre-rust/CONTRACT.md`; the reviewed six-body native relation is in the unchanged `PROOF.md`. This bridge concerns output **values** under that proof's admitted-preflight, canonical-UTF-8, stable valid storage, ordinary successful allocator/callee and no-wrap premises. It does not replace any opaque callee with an invented physical ABI.

The production source is `src/visor-move-request/src/lib.rs`. `&str` supplies canonical UTF-8 and safe immutable slices. The explicit scalar matches in `is_target_whitespace` give precisely W = U+0009..000D, 0020, 0085, 00A0, 1680, 2000..200A, 2028, 2029, 202F, 205F, 3000. `chars().all` is true for empty inputs. The filter only decides omission: a retained argument passes its original `as_bytes()` unchanged. This implements the collector's use of the trim result's length while preserving the original pointer/length for quoting, for both the initial and later retained operands.

`admission` spells out the exact raw, single and double byte languages extracted from the target constants. Raw admits `+-./0123456789:@ABCDEFGHIJKLMNOPQRSTUVWXYZ]_abcdefghijklmnopqrstuvwxyz`; single excludes apostrophe, backslash and caret; double excludes exclamation, dollar, caret and backtick. These are byte classes, not a host shell parser or a Unicode escaping library.

For every nonempty suffix, `append_quoted` starts with mask 7 and length zero, except an initial caret starts with mask 2 and length one. At each accepted byte the mask is the intersection of all selected byte classes. At the first zero intersection the conflicting byte remains unconsumed and the previous nonzero mask selects raw, then single, then double by lowest surviving bit. The special initial caret is admitted into a single-quoted chunk; an ordinary initial byte always has at least one admitted class. Thus each chunk has positive length, the scan terminates, and repeated calls consume the exact original byte sequence in order. Chunk slices are byte slices, so internal boundaries do not require UTF-8 alignment. Rendering uses the native quote bytes, with backslash insertion before exactly double quote, dollar, backslash and backtick in a double-quoted chunk.

A positive chunk of k input bytes emits at most 2k+2 <= 4k bytes; raw emits k and single emits k+2 <= 3k. Concatenating chunks therefore emits at most 4n for a retained operand of n bytes. `mv` plus at most two spaces and two operands emits at most `4*(s+d)+4`. The checked u64 addition and bound `s+d <= 2^61-2` imply a result at most `2^63-4`, with no multiplication overflow. The host usize conversion is separately checked. One fallible `Vec::try_reserve_exact` reserves at least the entire bound; under ordinary successful host allocation all subsequent extensions stay inside that capacity. Safe ownership removes physical aliasing from this new API; it does not prove the original allocator's freshness or preservation.

Both original operands are checked for NUL before construction. W does not contain NUL, so any operand containing it would be retained and would reach the native mode-zero NUL failure under the native ordinary-return premises. The Rust `EmbeddedNul` variant projects only that no-request condition. It does not claim the factory's returned word, target error layout, allocation chronology or cleanup trace. Length refusal and host allocation failure are chosen API policies. The coarse reservation differs from the native growth sequence deliberately; value equality on successful allocation is the claim.

The library always begins with `mv`, visits source before destination, adds one ASCII space for each retained operand, and returns raw option byte 1. It exposes no preflight, subprocess, shell or filesystem operation. In particular a quoted operand can contain `2>&1`, so option 1 is not an unconditional quiet-wrapper guarantee. No argument-option validation, path normalization, actual move effect or preparation-policy predicate is implemented.

The frozen oracle predates the Rust source. Instead of production's shrinking mask, it independently takes the longest prefix of each permitted byte language and chooses the greatest length, breaking ties in raw/single/double priority; the reviewed set-intersection argument relates these algorithms. The compiled input-only client links the actual Cargo library and receives only input TSV on stdin. It has no expectation file import or expected-value argument. The Python parent reads expectations and compares full raw stdout without normalization; this is explicit data-flow separation, not filesystem isolation. Finite corpus results supplement this all-input value argument and cannot establish original runtime or compiled-byte equivalence.
