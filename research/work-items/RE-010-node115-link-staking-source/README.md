# Node 1.1.5 link-staking state transitions

This is bounded partial progress for issue #3928. Prior [#2126](https://github.com/lalalune/hyperliquid-source/pull/2126) mapped the request/finalize paths; [#4288](https://github.com/lalalune/hyperliquid-source/pull/4288) separately examined conversion-unwind cleanup. Neither provided this owned state implementation. The present work models the selected normal-return wrapper and logical state using real keyed lookup and mutation.

Raw mode zero requests a link: the payload key must occur in the staked-key set, the two 20-byte keys must differ, and neither relevant relationship may have a nonzero tag. It then inserts or replaces the caller's relationship with tag 0 and the payload key. Every nonzero mode finalizes: the payload key must already hold tag 0 with the caller as peer, and the caller's relationship must have no nonzero tag. The payload relationship becomes tag 1, followed by the caller relationship becoming tag 2. If the two keys alias in finalization, the second write is retained. Rejections have the native inner status `0x16f`; success has `0x1a2`, with wrapper outer tags `0x0f` and `0x0e` respectively. The owned error enum identifies selected diagnostic branches; it is not the native allocated error payload or ABI.

The `BTreeSet` and `BTreeMap` are logical owned representations. Premises include valid keyed collections and normally returning allocation and lookup helpers. Decoder, caller authorization, live staking balances, physical map layout, allocator failure, unwind, and transactional rollback are outside scope. No two-write atomicity is claimed.

Static evidence authenticates the original Linux x86-64 node 1.1.5 image, SHA-256 `a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301`. Seven full FDE windows contain 5,245 bytes / 1,255 decoded instructions. The verifier binds 53 selected instruction/relocation facts, including the 20-byte comparator and 21-byte relationship replacement, and rejects corrupted facts with outer digest/window checks bypassed. This is static evidence, not a native runtime equivalence claim.
