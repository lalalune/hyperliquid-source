## Selector and copy

The copy IS a Duff's-device loop (0x6397e10..0x6397f7a), but only its dispatch tail is reachable — its 8-at-a-time body is value-dead. The length is *r8 (`mov (%r14),%rdx` at 0x6397de2, r14 = entry r8); if the length is exactly 4, the dword from the stack temp 0x4(%rsp) is stored whole to *rcx (`mov %esi,0x0(%r13)` at 0x6397deb, r13 = entry rcx) and the window exits 0 (`xor %ebp,%ebp` at 0x6397def). A null dest or null length pointer also exits 0 (`je 0x6397def` at 0x6397ddb / 0x6397de0). Otherwise n = min(len,4) (`mov $0x4,%edi` at 0x6397e10, `lea 0x4(%rsp),%r9` at 0x6397e15, `cmp %rdi,%rdx` at 0x6397e1a, `cmova %rdi,%rdx` at 0x6397e1d); n is saved in r10d (`mov %edx,%r10d` at 0x6397e21); n == 0 goes straight to the writeback (`test %edx,%edx` at 0x6397e24, `je 0x6397f80` at 0x6397e26). The first byte is copied at index rbx (`movzbl (%r9,%rbx,1),%r11d` at 0x6397e2c, `mov %r11b,0x0(%r13,%rbx,1)` at 0x6397e3f) — rbx is 0 on the copy path because the caller-condition or forces it (`or 0x50(%rsp),%rbx` at 0x6397d6d, `je 0x6397db0` at 0x6397d72); the done-jae (`jae 0x6397f80` at 0x6397e47) exits only when r12d(1) >= n, i.e. n <= 1; for n in 2..4, r8d = (n-1)&7 in {1,2,3} (`lea -0x1(%rdx),%r8d` at 0x6397e31, `and $0x7,%r8d` at 0x6397e3b) dispatches to the tail entries (0x6397ee3/0x6397ed2/0x6397ec1), which copy the remaining bytes and exit at the tail-end jae (`jae 0x6397f80` at 0x6397ef7). The 8-at-a-time body (0x6397efd..0x6397f7a, back-edge `jb 0x6397efd` at 0x6397f7a) is value-dead: its dispatch entry (`je 0x6397efd` at 0x6397e50) fires only when (n-1)&7 == 0, i.e. n == 1, but then the pre-dispatch jae already exited; and its fall-through entry from the tail-end jae requires r12d < n after the tail, but the tail leaves r12d == n. The tail entries for r8d in {4,5,6,7} (0x6397eb0/0x6397e9f/0x6397e8e/0x6397e7e) are likewise never entered — they would require n in {5,6,7,8}, impossible since n <= 4. The writeback stores *r8 = n (`mov %rdx,(%r14)` at 0x6397f80) and exits 22 (`mov $0x16,%ebp` at 0x6397f83).
