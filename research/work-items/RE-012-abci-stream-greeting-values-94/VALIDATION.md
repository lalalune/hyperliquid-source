The86 controls are actual checks, not proposed tests. They include target

refusals. `controls.json` records each rejection and exact changed bytes where
applicable; `controls/*.txt.gz` retain actual provider output. Binding controls
prove the checker refuses changed evidence, not that arbitrary mutated machine
programs have a particular runtime behavior. None was executed or emulated.
