# RE-009 · Small tree history conversion to flat rows

Target Linux x86-64 Node #115 SHA-256 a6e2897cd051213d004802deca416e8eca62b7a8278fa39f249e98c3867b5301. The selected tree cutoff wrappers are 0x4de4a60 and 0x4de5ad0. This packet covers the representation change after the partition count, including the two collectors at 0x5b9b710 and 0x5b74f20.

Both wrappers check whether the original descriptor still has a tree sentinel after the split. In that case the retained count is compared with 31, with larger counts bypassing conversion of the retained descriptor. The split-out count gets its own comparison with 31. Larger counts preserve the staged tree descriptor on that branch. Thus the selected conversions are per side and include count 31. On the retained path the root pointer and count fields are cleared before collection, and the selected normal continuation republishes a flat descriptor with start zero.

Each collector derives an initial byte request from 40 times its input iterator count. On its selected forward path it calls the same cursor boundary, 0x51e06d0, and stops writing rows when the returned node pointer is zero. A returned slot supplies one key from node +0x168+8×slot and one value from node +32×slot. The collectors place the key first and the 32-byte value second and advance by 40 bytes. They return the written count independently from the allocation field. The wrapper's selected split-out flat descriptor has start zero. The two collectors' row projection bytes match; their distinct callers and relocation windows remain separate evidence.

This describes the selected normal conversion after a successful split with valid iterator bounds and ordinary helper returns. Complete cursor semantics, allocation growth and unwind recovery are outside this packet.
