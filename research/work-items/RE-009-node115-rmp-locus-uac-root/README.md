# RE-009 #115 named Locus uac and independent compact count parity

Compare `exchange.locus.uac` at raw path `[0,11]` using a named checkpoint, raw ABCI reference and separately supplied compact count witness. Each input has a distinct SHA-256 pin. The reference must reproduce its own raw digest and report H at its inner Context height leaf.

The named writer `0x52d4c90` has source rows at `+0x8`, length at `+0x10`, 232-byte stride, Address at row `+0xd0` and activity record at row base. Raw visitor `0x46a5870` collects matching key/value coordinates. Value visitor `0x3b83280` is the same native function used for the single `ctr.ac` record. Here each of the 23 leaf inputs accumulates every user row in named order, resulting in one digest per ordered column. It preserves the same zero- and epoch-default semantics. `[0,11,0]` hashes the ordered Address stream. `[0,11,1]` holds the complete activity column tree. Empty rows bypass both streams.

The count leaf `[0,11,2]` hashes little-endian storage word `+0x30` from the compact `uac` source object. The verifier does not derive this word from the named row count. It accepts a pinned JSON witness with exactly `height`, `checkpoint_sha256`, and `uac_compact_count`. The producer should obtain the word through an independent compact capture or tested reconstruction. Associating witness metadata to the checkpoint authenticates the supplied pair but cannot verify how a producer obtained that word. The receipt reports both counts independently. The probe that deliberately varies them is a synthetic discrimination control.

Use the helper paths and pins in `compare_uac.py`, including the named Locus [`ctr.ac` packet #7796](https://github.com/lalalune/hyperliquid-source/pull/7796) and its transitive helpers. Run `python -B research/work-items/RE-009-node115-rmp-locus-uac-root/verify.py --helpers PATH --rustc PATH` from the checkout root. The genuine log covers static ELF evidence and synthetic empty, two-row, count, wrong-reference and wrong-witness comparisons. The captured executable was never run.
