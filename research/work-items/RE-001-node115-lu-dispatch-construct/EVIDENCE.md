## Evidence

Resolver `0x636e340..0x636e817` (1,239B, 305 strict lines, whole FDE characterized): entry saves registers and calls `strchr(name, '.')` (PLT `0x63f1aa0`); a dotless name takes a `strlen` single-segment path. Per segment it scans the current node's children (stride `0x28`, count at node `+0x10`, children at `+0x18`), comparing `strlen(child+0x08 name)` to the segment length then `strncmp` (PLT `0x63f1500`), and appends the matched index past the walked prefix (`mov %rbx,0x0(%rbp,%r15,8)`; `%rbp` = array end, `%r15` = segment counter), bounded by `*count_ptr` (overflow returns 2). Callers subtract the walked prefix from `*count_ptr` before the call and add it back after, so it ends holding the resolved total length. Numeric branch: flag-0 child → `strtol` base 10 (`0x63be700`); `-1` returns 2; the parsed index goes to the resolver function at `children[0]+0x08` called as `(ctx, array_end, *count_ptr, parsed_index)`; non-flag-0 `children[0]` jumps to a 10-byte `ud2` trap stub FDE `0x636e32e..0x636e338` — the resolver FDE's only out-of-FDE jump. Success with a non-NULL out-slot writes the final node to `*out_slot` and returns 0; NULL out-slot returns 0 directly. Direct calls: `strchr`, `strlen`, `strncmp`, `strtol`, plus indirect resolver calls. Direct resolver callers: dispatcher `0x63a9287` (cited from #255), sibling `0x63a8f37`, invoke `0x63a891c`; tail-jump caller: wrapper `0x63a89db`. No lea/movabs address-taken sites, no `.rela.dyn` pointers (all-REX-form scan).

Sibling `0x63a8d00..0x63a8fe8` (744B, 196 strict): same walk, same leaf gate (`+0x20 == 0` required), resolver called with out-slot NULL (`xor %ecx,%ecx`), status returned, no handler invoked. All jumps internal; direct calls only init `0x63a8240` + resolver. 19 E8 sites, 0 E9.

Dispatcher `0x63a8ff0..0x63a93ba` (cited from #255, not re-claimed): 54 E8 sites, 0 E9, in 5 FDEs (7/7/23/5/12). Sibling + dispatcher name inventory (36 DISP + 8 SIBL distinct, all stat fields) and per-site (FDE, name, length class) records are in `records.json` under `census`. No site passes `'reset'`, `'mutexes'` as a DISP name, or any dotted name ending in reset. No `$0xb` immediate in any of the seven caller FDEs (objdump scan with `#` comment suffixes stripped).

Invoke `0x63a88a0..0x63a8984` (228B, characterized): init check, resolver from root with the caller's name, stack out-slot, capacity 7; on success checks node and `+0x20` handler non-NULL and `call`s the handler (return 2 on failure, 11 on init failure). 0 E8, 1 E9 (`0x635df37` from the gated helper), 0 address-taken, 0 rela pointers.

Walk-invoke `0x63a89f0..0x63a8cff` (783B, gate exhibited): root node + root children loads, dispatcher-identical walk, completion requires final node non-NULL and `+0x20 != 0` (complement of the dispatcher/sibling gate), then restores caller arguments and tail-calls the handler (`jmp *%rax` at `0x63a8c3f`). No name input. 1 E8 (`0x635e07d` from the second gated helper), 0 E9, 0 address-taken, 0 rela pointers.

Gated helper → invoke `0x635dee0..0x635df87` (167B, 49 strict, exhibited): reads global flag `0x64ffab4`; if set, calls predicate `0x634f0b0` and returns 11 when nonzero; builds a TLS context (`%fs:0x330` check + `0x63ef8e0` getter path); tail-jumps to invoke with the caller's first argument as the name (`0x635df37` → `0x63a88a0`, the FDE's only out-of-FDE direct jump). 110 E8 sites in 6 FDEs (2/2/92/1/12/1). The three `stats.background_thread.*` names resolve under `stats`, not under `stats.mutexes`; the lone `'background_thread'` resolves at root index 2 (handler `0x6386940`).

Gated helper → walk-invoke `0x635e020..0x635e0c5` (165B, characterized): same gate structure, `call`s walk-invoke with the caller's first two arguments as `(array, length)`, returns its status. 56 E8 sites (FDE 5: 53, FDE 6: 3), 0 E9, 0 address-taken, 0 rela pointers.
