# Node115 InfoRequest logical values

This real isolated Rust package reconstructs all 55 logical request-value
branches of ELF VA 0x273bf30..0x273ebc0, including its nested FileSnapshot
constructor. It returns typed values and observed field construction order.
It does not claim the original enum/value ABI, native allocator, full
dependency graph, HTTP endpoint, later wire bytes or whole-node equivalence.

The API preserves exact u64/u32 values, valid UTF-8 strings and full 20-byte
lowercase 0x-prefixed addresses. Absent optional user/leader addresses remain
explicit null fields. Nested L4Snapshots omits a missing coin and false
includeL4Details, while its other booleans and ordinary request booleans are
present in both states. The native tags borrowLendUserState,
borrowLendReserveState, allBorrowLendReserveStates and aqav2InterestHistory
are retained as observed, independent of inferred source-type labels.

The 190 whole-value expectations were frozen before this Rust source.
See research/work-items/RE-005-info-request-value-115 for the evidence.
No original target execution/emulation or component gate change is claimed.
