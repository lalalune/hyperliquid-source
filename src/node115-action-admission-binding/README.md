# node115-action-admission-binding

Target-bound mapping of92 exact wire action names to nominal in-memory tags and five signer admission classes. [Evidence and all bindings](../../research/work-items/RE-017-node115-action-admission-binding/README.md) are independently rebound to six original-ELF serializer copies and three admission gates.

`from_wire_name` is case-sensitive; `from_index` addresses the92 recovered catalogue entries; `from_internal_word` reproduces the0x86 bias and index20 below-base alias, rejecting words above the recovered domain. The class describes a routing requirement, not authorization. Payload decoding, signature verification, membership/list initialization, user resolution and action execution remain external contracts. This crate cannot approve an action.
