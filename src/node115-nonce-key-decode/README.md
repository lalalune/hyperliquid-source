# node115-nonce-key-decode

Offline reconstruction of the selected nonce-record twenty-byte field visitor. Call `decode_key` with an already decoded JSON string's bytes. The exact forty-byte input gate, optional lowercase `0x`, whitespace skipping, unmatched-nibble discard and zero-filled output suffix follow the pinned native call chain.

See [the evidence packet](../../research/work-items/RE-004-node115-nonce-key-decode/README.md) for native addresses, assumptions, validation and limitations. This is not a general address validator, JSON parser, admission check or persistence implementation.

```sh
cargo +1.95.0 test --offline --locked --manifest-path src/node115-nonce-key-decode/Cargo.toml
```
