# Node115 spot metadata decimal conversion

Independently authored MIT no_std logical table API. Converts a raw unsigned
amount only when divisible by10^(8-decimal), after both metadata index guards.
The caller supplies an initialized16-byte output window; inactive payload and
padding are preserved exactly. Diagnostic observations stop at native PCs and
do not implement native error handlers. Slice layouts are research views, not
the native32/344-byte row ABI or an inferred public asset interface.

Direct rustc1.94.1, edition2021, no external dependencies or invented original
Cargo graph. Evidence, original-first streams and build/control commands are
in research/work-items/RE-004-spot-decimal-115. No economic units, full metadata
producer, Linux build recipe, machine-code equality or complete node claim.
