# node115-fee-history-reward

Bounded, independently authored `no_std + alloc` arithmetic for constructing
fee-history reward rows and selecting from caller-ordered rows. The separate
caller-supplied total and row order are explicit premises. This is not an RPC
implementation, sorting routine, native ABI or complete fee-history model.

See `research/work-items/RE-011-node115-fee-history-reward-source/README.md`
for pinned target evidence, earlier work, reproduction and limits.
